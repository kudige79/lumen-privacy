Getting started

  • Open Lumen. It starts on the Drop Zone tab.
  • Drag in a folder to process its supported files, or drop individual files to rename just those. You can also use Choose Folder or Choose Files.
  • Click Process Files, then review the proposed names on the Results tab.
  • Approve the names you want, edit any you wish to change, then click Execute Renames. Nothing is renamed without your approval.
  • Changed your mind? The Revert Renames tab can restore eligible files from a previous rename run.

A full User Guide is built into the app under the Help & Privacy tab.

Common questions

Is my data private?

By default, document analysis runs on your Mac using an on-device model, and no document content is transmitted. Cloud analysis is optional and off by default, and uses your own API key. Before Lumen first sends file-related content to a provider, it shows a per-provider consent prompt. Lumen asks again if the disclosure materially changes, and photo naming has its own consent. Full details are in the Privacy Policy.

How do software-update checks work?

Automatic update checks are on by default in Lumen 1.2.1. The control is in Settings → Advanced → Software Updates.

When on, Lumen contacts lumen-ai.eu after launch when a daily check is due. The request identifies Lumen and its version; the server also receives your IP address and the time. No document data or Mac system profile is sent. Available updates download from GitHub Releases. Turn this off to stop automatic checks; you can still use Lumen → Check for Updates… at any time.

The on-device model will not download.

The on-device model requires an Apple-silicon Mac with 24 GB+ memory and a download of approximately 8.26 GB over the internet. Open Settings → AI Provider and use the Download control. If you are on an Intel Mac, use one of the optional cloud providers with your own API key instead.

macOS asked for permission to a folder when I renamed files.

For document and photo processing, Lumen is sandboxed and accesses only files and folders you select. Renaming a file in place needs write access to its parent folder, so macOS may present a standard folder-access panel when you execute renames. Lumen remembers access where possible, but macOS may ask again.

A Pages, Numbers, or Keynote file did not name well.

Lumen reads an embedded PDF or image preview when one is available. Many modern iWork files provide only a first-page preview, so placing identifying text on page one helps. If Lumen cannot extract usable text, the file is routed to the Unprocessed tab for quick manual naming.
